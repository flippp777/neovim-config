# neovim-config

My Neovim setup, written in Lua and managed with [lazy.nvim](https://github.com/folke/lazy.nvim).

- **LSP & completion:** mason, nvim-lspconfig (Lua, C/C++, Python), none-ls, jdtls for Java
- **Debugging:** nvim-dap + dap-ui
- **Navigation:** telescope, neo-tree, oil, harpoon
- **Editing:** treesitter, autopairs, comment, which-key, trouble
- **LaTeX:** vimtex
- **UI:** catppuccin, lualine, alpha dashboard, indent-blankline, toggleterm, lazygit

## Install

```bash
git clone https://github.com/flippp777/neovim-config ~/.config/nvim
```

Plugins install automatically on first start.
